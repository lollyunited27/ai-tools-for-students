# AI-сервисы для студентов: практическое сравнение

> Портфолио-проект о применении AI-инструментов в учебных задачах.

## О проекте

Этот проект сравнивает AI-сервисы на типовых задачах студента: объяснение сложной темы, создание конспекта, поиск информации, подготовка презентации, работа с текстом и планирование учёбы.

Главный вопрос исследования:

> Какой AI-сервис лучше подходит для каждой студенческой задачи?

Это не рейтинг «лучшей нейросети вообще». Сервисы могут быть сильны в разных сценариях, поэтому итоговые рекомендации будут привязаны к конкретным задачам и условиям использования.

## Что входит в исследование

Планируемые сервисы:

- ChatGPT
- Claude
- Gemini
- MiniMax
- DeepSeek
- Perplexity
- NotebookLM

Фактически в итоговую выборку попадут только сервисы, к которым удалось получить доступ на момент тестирования. Доступность функций и бесплатных лимитов может меняться.

## Тестируемые задачи

1. Объяснение сложной учебной темы.
2. Создание конспекта.
3. Поиск информации с источниками.
4. Подготовка структуры презентации.
5. Проверка и улучшение текста.
6. Планирование учебной недели.
7. Изучение английского языка.
8. Создание простого AI-агента или прототипа.

## Методика

Для каждого доступного сервиса используются одинаковые или максимально близкие запросы. Ответы фиксируются, а затем оцениваются по единой шкале от 1 до 5.

Подробные правила находятся в [`methodology.md`](methodology.md), сами задания — в [`prompts/test-prompts.md`](prompts/test-prompts.md).

## Критерии оценки

| Критерий | Что оценивается |
|---|---|
| Качество | Практическая полезность результата |
| Точность | Наличие ошибок, искажений и выдуманных фактов |
| Русский язык | Понимание запроса и качество формулировок на русском |
| Простота | Насколько легко начать пользоваться сервисом |
| Скорость | Время до получения пригодного результата |
| Бесплатный доступ | Возможности без обязательной оплаты |
| Работа с файлами | Загрузка и анализ документов |
| Источники | Наличие проверяемых ссылок и подтверждений |

## Ограничения

- Исследование отражает результаты конкретных тестов, а не абсолютные свойства продуктов.
- Ответы могут зависеть от версии модели, тарифа, региона, настроек и даты проверки.
- Оценки субъективны, но выставляются по заранее описанным правилам.
- Нельзя считать отсутствие функции доказательством того, что она недоступна всем пользователям.
- Скриншоты и ссылки будут добавляться только при необходимости и без персональных данных.
