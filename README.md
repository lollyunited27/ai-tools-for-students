# AI-сервисы для студентов: практическое сравнение

> Портфолио-проект Богдана о применении AI-инструментов в учебных задачах.

## О проекте

Этот проект сравнивает AI-сервисы на типовых задачах студента: объяснение сложной темы, создание конспекта и поиск информации с источниками.

Главный вопрос исследования:

> Какой AI-сервис лучше подходит для каждой студенческой задачи?

Это не рейтинг «лучшей нейросети вообще». Сервисы могут быть сильны в разных сценариях, поэтому выводы привязаны к конкретным задачам и условиям тестирования.

## Итоговая выборка

В текущую итоговую выборку входят только три сервиса:

- Claude;
- Gemini;
- MiniMax.

GPT через Notion AI не включён: это не полноценный отдельный тест ChatGPT. Другие сервисы из первоначального плана также не входят в текущую выборку.

## Тестируемые задачи

Проведены и оформлены задачи 1–3:

1. Объяснение сложной учебной темы.
2. Создание конспекта.
3. Поиск информации с источниками.

Задачи 4–8 пока не тестировались:

4. Подготовка структуры презентации.
5. Проверка и улучшение текста.
6. Планирование учебной недели.
7. Изучение английского языка.
8. Создание простого AI-агента или прототипа.

## Методика

Для каждого сервиса использовались одинаковые или максимально близкие запросы. Ответы фиксировались, а затем оценивались по единой шкале от 1 до 5.

Подробные правила находятся в [`methodology.md`](methodology.md), задания — в [`prompts/test-prompts.md`](prompts/test-prompts.md), исходный материал для теста конспектирования — в [`prompts/source-text-for-summary-test.md`](prompts/source-text-for-summary-test.md).

В задаче 2 более поздний идентичный ответ MiniMax не учитывался как новая попытка. В задаче 1 полные исходные ответы не сохранились, поэтому в `results/raw/` размещены честные записи наблюдений без реконструкции текста.

## Критерии оценки

| Критерий | Что оценивается |
|---|---|
| Качество | Практическая полезность результата |
| Точность | Наличие ошибок, искажений и выдуманных фактов |
| Русский язык | Понимание запроса и качество формулировок на русском |
| Простота | Насколько легко начать пользоваться сервисом |
| Скорость | Время до получения пригодного результата |
| Бесплатный доступ | Возможности без обязательной оплаты |
| Работа с файлами | Загрузка и анализ документов |
| Источники | Наличие проверяемых ссылок и подтверждений |

## Ограничения

- Исследование отражает результаты конкретных тестов, а не абсолютные свойства продуктов.
- Ответы зависят от версии модели, тарифа, региона, настроек и даты проверки.
- Оценки субъективны, но выставляются по заранее описанным правилам.
- Бесплатный доступ и работа с файлами в текущем цикле не тестировались, поэтому оценки по ним не выставлены.
- Для источников проверялись открываемость, библиографические данные и соответствие заявленному содержанию; вторичные материалы явно отмечены.
- Скриншоты и ссылки добавляются только при необходимости и без персональных данных.
