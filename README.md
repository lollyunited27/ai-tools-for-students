# AI-сервисы для студентов: практическое сравнение

> Портфолио-проект Богдана о применении AI-инструментов в учебных задачах.

## О проекте

Здесь собраны результаты сравнения четырёх AI-сервисов на восьми обычных студенческих задачах: от объяснения темы и конспекта до планирования недели и проектирования простого AI-ассистента.

Главный вопрос проекта:

> Какой сервис лучше помогает в каждой конкретной учебной задаче?

Это не попытка назвать одну «лучшую нейросеть». Каждый сервис может оказаться сильнее в своём сценарии, поэтому выводы привязаны к задаче и условиям теста.

## Итоговая выборка

В итоговую выборку входят четыре сервиса:

- Claude;
- Gemini;
- MiniMax;
- официальный ChatGPT.

GPT через Notion AI не включается как отдельный тест и не заменяет прямой тест официального ChatGPT. Другие сервисы из первоначального плана также не входят в текущую выборку.

## Тестируемые задачи

Задачи 1–8 проведены и оформлены для Claude, Gemini, MiniMax и официального ChatGPT:

1. Объяснение сложной учебной темы.
2. Создание конспекта.
3. Поиск информации с источниками.
4. Подготовка структуры презентации.
5. Проверка и улучшение текста.
6. Планирование учебной недели.
7. Изучение английского языка.
8. Создание простого AI-агента или прототипа.

## Методика

Для каждого сервиса использовались одинаковые или максимально близкие запросы. Ответы сохранялись и оценивались по одной шкале от 1 до 5.

Правила тестирования описаны в [`methodology.md`](methodology.md). Все задания собраны в [`prompts/test-prompts.md`](prompts/test-prompts.md). Для теста конспектирования использовался [`source-text-for-summary-test.md`](prompts/source-text-for-summary-test.md), для редактуры использовался [`source-text-for-editing-test.md`](prompts/source-text-for-editing-test.md).

В задаче 2 поздний идентичный ответ MiniMax не считался новой попыткой. Полные ответы Claude, Gemini и MiniMax по задаче 1 не сохранились, поэтому в `results/raw/` лежат честные записи наблюдений без реконструкции текста. Для ChatGPT сохранена транскрипция видимого ответа со скриншотов.

## Критерии оценки

| Критерий | Что оценивается |
|---|---|
| Качество | Практическая полезность результата |
| Точность | Наличие ошибок, искажений и выдуманных фактов |
| Русский язык | Понимание запроса и качество формулировок на русском |
| Простота | Насколько легко начать пользоваться сервисом |
| Скорость | Время до получения пригодного результата |
| Бесплатный доступ | Возможности без обязательной оплаты |
| Работа с файлами | Загрузка и анализ документов |
| Источники | Наличие проверяемых ссылок и подтверждений |

## Ограничения

- Исследование отражает результаты конкретных тестов, а не абсолютные свойства продуктов.
- Ответы зависят от версии модели, тарифа, региона, настроек и даты проверки.
- Оценки субъективны, но выставляются по заранее описанным правилам.
- Бесплатный доступ и работа с файлами в текущем цикле не тестировались, поэтому оценки по ним не выставлены.
- Для источников проверялись открываемость, библиографические данные и соответствие заявленному содержанию; вторичные материалы явно отмечены.
- В задаче 8 оценивалось качество описания прототипа. Реализация в конкретных no-code-инструментах, лимиты текста, тарифные условия, хранение истории и фактическая обработка персональных данных отдельно не проверялись.
- Скриншоты и ссылки добавляются только при необходимости и без персональных данных.
