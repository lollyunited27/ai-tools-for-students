# Исходный текст для теста редактуры

## Как использовать

Для задачи 5 скопируй в сервис **только текст из блока ниже** после единого промпта из [`test-prompts.md`](test-prompts.md). Не передавай сервису контрольные точки из этого файла.

## Текст для редактуры

```text
В небольшом интернет-магазине решили внедрить новую форму еженедельного отчёта по продажам. Руководитель считает, что эта форма обязательно увеличит удовлетворённость клиентов на 50%, хотя измерения удовлетворённости ещё не проводились.

В марте продажи выросли сразу после запуска email-рассылки. Значит, рассылка была единственной причиной роста продаж, и проверять сезонность, изменение цен или действия конкурентов не нужно.

Для отчёта использовали данные из CRM, поэтому они полностью точные и не требуют проверки. Данные анализировалось раз в неделю, а сотрудники должен быстро принимать решение по каждому показателю.

Новая форма отчёта — это супер-эффективное решение, которое вообще точно сделает работу компании лучше. Руководству следует немедленно применять её во всех отделах.
```

## Контрольные точки для оценки ответа

Сервису не передаётся этот список. Он нужен для последующей проверки результата.

1. **Неподтверждённое количественное утверждение:** нельзя утверждать, что новая форма отчёта обязательно увеличит удовлетворённость клиентов на 50%, если измерения ещё не проводились.
2. **Логическая ошибка причинности:** рост продаж после email-рассылки не доказывает, что рассылка была единственной причиной; нужно проверить сезонность, цены, действия конкурентов и другие факторы.
3. **Ошибка о качестве данных:** выгрузка из CRM не гарантирует полную точность данных; необходима проверка качества данных.
4. **Грамматика:** «Данные анализировалось» → «Данные анализировались»; «сотрудники должен» → «сотрудники должны».
5. **Стилистика и академичность:** «супер-эффективное», «вообще точно», «немедленно применять» — оценочные и категоричные формулировки, которые следует заменить на нейтральные.
6. **Сохранение смысла:** улучшенная версия должна описывать внедрение формы отчёта и возможную пользу, но не добавлять новые подтверждённые факты, показатели или результаты.
