# Тестовые промпты

## Общие правила

- Копируй промпт без изменений для каждого сервиса.
- Если в конкретном сервисе есть отдельное поле для файла или режима поиска, используй его и зафиксируй это.
- Не добавляй сервису подсказки, которых нет в тексте.
- После ответа сохрани результат и запиши дату, модель/режим и тариф.

## 1. Объяснение сложной учебной темы

```text
Объясни студенту 2 курса простым, но точным языком тему «эластичность спроса по цене». Дай определение, формулу, расшифруй обозначения, приведи один числовой пример и объясни практический смысл результата. В конце перечисли три типичные ошибки при понимании этой темы.
```

## 2. Создание конспекта

Для этого теста используй один и тот же учебный текст из файла [`source-text-for-summary-test.md`](source-text-for-summary-test.md). Скопируй в сервис сначала промпт ниже, затем сразу после него вставь полный исходный текст без изменений.

```text
Составь структурированный конспект учебного материала ниже. Выдели основные понятия, тезисы, причинно-следственные связи и термины. Не добавляй сведений, которых нет в материале. В конце составь 5 вопросов для самопроверки и укажи, на каких фрагментах материала основан каждый вопрос.

Учебный материал:
[ВСТАВИТЬ ПОЛНЫЙ ТЕКСТ ИЗ source-text-for-summary-test.md]
```

При проверке отдельно отметь: сохранены ли все три уровня управленческих решений; не добавил ли сервис факты, которых нет в тексте; понятны ли причинно-следственные связи; действительно ли вопросы для самопроверки опираются на исходный материал.

## 3. Поиск информации с источниками

```text
Подбери 5 проверяемых источников для подготовки учебного сообщения на тему «применение искусственного интеллекта в бизнес-аналитике». Для каждого источника укажи название, автора или организацию, год публикации, ссылку и одну идею, которую можно использовать. Не выдумывай источники; если не уверен в данных, прямо укажи это.
```

## 4. Структура презентации

```text
Составь структуру презентации на 8 слайдов для студентов 2 курса на тему «Как AI-инструменты помогают анализировать бизнес-процессы». Для каждого слайда укажи заголовок, 2–4 ключевых пункта и идею визуального материала. Не пиши полный текст выступления.
```

## 5. Проверка и улучшение текста

```text
Проверь текст ниже как редактор. Сначала перечисли фактические, логические, грамматические и стилистические проблемы. Затем предложи улучшенную версию, сохранив исходный смысл и нейтральный академический стиль. Не добавляй новые факты без отдельной пометки.

Текст для проверки:
[ВСТАВИТЬ ОДИН И ТОТ ЖЕ ТЕКСТ]
```

## 6. Планирование учебной недели

```text
Составь реалистичный план учебной недели для студента 2 курса. Условия: 4 учебных дня, 5 учебных дисциплин, одна большая письменная работа со сроком через 7 дней, 5 часов подработки в неделю, ежедневная дорога занимает 1 час, сон — не менее 8 часов. Распредели задачи по дням, заложи время на отдых и объясни приоритеты. Не планируй больше 2 крупных задач на один день.
```

## 7. Изучение английского языка

```text
Ты — помощник по английскому языку для студента уровня A1–A2. Объясни разницу между словами «borrow» и «lend» на русском языке, приведи по 3 простых примера с переводом, а затем дай небольшое упражнение на 5 предложений. Не показывай ответы к упражнению сразу.
```

## 8. Создание простого AI-агента или прототипа

```text
Предложи простой прототип AI-ассистента для студента без навыков программирования. Опиши проблему пользователя, целевую аудиторию, роль ассистента, системные инструкции, входные данные, ожидаемый результат, ограничения и 3 тестовых сценария. Решение должно быть реализуемо в no-code-инструменте и не должно требовать доступа к персональным данным.
```
